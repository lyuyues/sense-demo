SENSE 老师设置

感官评定表的最后一步：边看一段准备视频，边把画面、声音、距离、节奏调到最适合这个孩子的样子。大约 5–10 分钟。

建议：用电脑或平板（手机请横屏），请打开声音（最好戴耳机），在安静的地方完成。按您对孩子的了解来调，不用和家长商量。

进入视频页面后：
1. 点右下角的 ⚙️ 齿轮，打开"调节"面板
2. 逐个调整滑块：亮度 / 饱和度 / 音调 / 人声音量 / 背景音乐音量 / 音效音量 / 空间距离 / 情节节奏。中间位置 = 一般孩子的默认值
3. 调整会马上反映在视频上，可以边播放边反复调
4. 想象这个孩子在看这段视频：调到他/她看着舒服、又能看进去的样子
5. 调好后点 确认设置，看到"已保存 ✓"就完成了，可以关掉页面
