SENSE 家长设置

家长/专家版对照系统 — 跳过孩子在画布上的互动环节，直接由家长在设置面板里手动拖动 8 个维度的滑块，生成对应的准备视频。

这是什么：与正式 SENSE 流程（孩子拖拽头像、涂色、调灯光等 5 个阶段来外化感官偏好）不同，这个版本让家长/专家直接设定参数，用于跟儿童互动外化的结果做对比实验。

进入视频页面后：
1. 点击播放器右下角的 ⚙️ 齿轮图标，打开"调节"面板
2. 逐个滑块调整：亮度 / 饱和度 / 音调 / 人声音量 / 背景音乐音量 / 音效音量 / 空间距离 / 情节节奏（中点 = 中性默认）
3. 调整后视频会实时应用新的画面滤镜和音频效果，可反复试听
4. 调好后点 确认设置 保存，视频会回到开头给孩子看
